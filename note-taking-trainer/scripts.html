Lecture scripts for recording

All lecture scripts, split into numbered parts. Each lecture starts on a new page when printed.

Recording tips

  • Speak at a natural lecture pace, slightly slower than conversation.
  • Record each lecture as one MP3 file. Use the file name shown under each title.
  • Write down the time (in seconds) when each numbered part starts. These are the audioStart times in the README. They let students replay one part.
