# davenab.github.io

Portfolio of AI-supported learning apps for academic English, by Dave Nab.

Live site: https://davenab.github.io

## Structure

- `index.html` — portfolio home page (app cards)
- `<app-name>/index.html` — each app lives in its own folder, e.g. `note-taking/`
- `.nojekyll` — tells GitHub Pages to serve files as-is

## Adding an app

1. Create a folder with the app's `index.html`.
2. In `index.html`, update that app's card: set the status to `Live` and add a `Try it →` link to the folder.
