# davenab.com

Dave Nab's website: AI learning apps, teaching resources, IELTS and General English courses.

Live site: https://davenab.com (served by GitHub Pages from `main`; DNS on Cloudflare).

## Structure

- `index.html` and the folders `apps/`, `resources/`, `ielts-courses/`, `ielts-mock-test/`, `general-english/`, `testimonials/`, `gallery/`, `about/`, `book/` are the website pages, generated by `_tools/build.py` (run `python3 _tools/build.py .`).
- `assets/` holds the shared CSS, JS and images.
- `<app-name>/` folders hold the self-contained learning apps, e.g. `note-taking-trainer/`.
- `CNAME` sets the custom domain; `.nojekyll` tells GitHub Pages to serve files as-is.
